## Overview

This is a Data Visualization group project that aims to create two separate dashboards using
PowerBI and Tableau dataviz tools. As a group, we decided to use the Airbnb dataset containing
Ireland property listings. After initial discussion, it was decided that Niall will use PowerBI
and Guilherme will use Tableau for the dashboard creations.

The original dataset can be found here: https://insideairbnb.com/get-the-data.
We download Ireland detailed data from 26 September, 2025 (listings.csv.gz, Detailed Listings data).
The download file had a zip file in it where the dataset `listings.csv` was within.
The `listings.csv` file as saved in this repository for reference.

## Tracks

After we have decided about technologies, we also decided about the approach for each member group.
Niall worked on his own aiming Customers trying to find a place for temporary rent, while Guilherme
worked on his own from the point of view of an Investor.

Please, find more information on the Group Report found in this repository.
